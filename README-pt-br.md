# PyBank
Sistema bancário desenvolvido em Python para aplicar fundamentos da linguagem e evoluir progressivamente com novos conceitos e funcionalidades.
## Sobre o Projeto
O PyBank é um projeto desenvolvido com o objetivo de colocar em prática os conceitos de Python que estamos aprendendo.

O projeto começa utilizando conceitos básicos da linguagem e será atualizado conforme avançamos nos estudos.
## Conceitos Utilizados

Atualmente, o projeto utiliza:

- Variáveis
- Entrada e saída de dados
- Condicionais (`if`, `elif` e `else`)
- Laços `while`
- Laços `for`

  ## Funcionalidades

- [ ] Consultar saldo
- [ ] Realizar depósitos
- [ ] Realizar saques
- [ ] Exibir histórico de operações
- [ ] Sistema de senha

## Tecnologias
- Python

## Objetivo
Além de desenvolver um sistema bancário funcional, este repositório serve para registrar nossa evolução no aprendizado de Python.

Novos conceitos e funcionalidades serão adicionados conforme avançamos nos estudos.
